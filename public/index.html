HOW TO USE
  1. Install the laptop helper from the helper folder (one-time setup).
  2. Start this web server and create a pairing code.
  3. Run the laptop helper and enter the code.
  4. Open the remote page on your phone and enter the same code.
  5. Click the slideshow window once to focus it. Use the phone's Next and Previous buttons.

SlideLink sends keyboard arrows to the active laptop window. It does not upload or read your slides.
